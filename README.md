# 🐦 Twitter Analytics Dashboard | Power BI Project

## 📊 Project Overview
This Power BI project analyzes over 10,000 tweets to understand engagement trends, posting behavior, and text length distribution.

## 🚀 Key Insights
- Most tweets are posted on **Fridays and Mondays**
- Engagement (likes & retweets) peaks during **evening hours**
- Shorter tweets gain slightly higher engagement
- Consistent decline in tweet activity from Jan–May 2023

## 📈 Dashboard Features
- **KPIs:** Total Tweets, Total Likes, Total Retweets, Avg Text Length
- **Visuals:**  
  - Tweets by Day of Week  
  - Tweets Over Time  
  - Engagement by Hour  
  - Text Length Distribution  
- **Filters:** Interactive slicers for month and day of week

## 🧰 Tools Used
- Power BI Desktop  
- DAX for calculated metrics  
- Data cleaned using Excel
